# Product

## Register

brand

## Users

Cambodian and international software developers, fintech engineers, and e-commerce merchants building payment systems with ABA Bank Cambodia and Bakong KHQR.

## Product Purpose

Provide an unofficial, edge-compatible TypeScript SDK and comprehensive documentation site to make ABA PayWay payment integrations fast, secure, type-safe, and reliable.

## Brand Personality

- **Trustworthy & Bank-Grade**: Cryptographic precision, security badges, clear disclaimer, and official KHQR/ABA aesthetics.
- **National Cambodian Identity**: Deep blue, crimson red, and Angkor Wat motifs reflecting Cambodian fintech innovation.
- **Developer-Centric**: Clear code snippets, zero fluff, instant copy commands, and comprehensive API references.

## Anti-references

- Generic AI SaaS templates with washed-out beige/cream palettes.
- Cluttered scam-like crypto pages with loud neon text.
- Confusing corporate jargon without direct runnable code.

## Design Principles

1. **Trust Through Precision**: Real working code examples, HMAC-SHA512 verification highlights, and clear unofficial transparency.
2. **National Fintech Pride**: Respectful Cambodian flag wave and authentic Bakong KHQR / ABA PayWay branding.
3. **Speed & Clarity**: High contrast, balanced hierarchy, and instant installation accessibility.

## Accessibility & Inclusion

- WCAG AA contrast standards for all body copy and badges.
- Reduced motion support for flag animations via prefers-reduced-motion.
- Semantic HTML tags and keyboard navigable buttons.
